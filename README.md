# Small Acts — Community Service Project

**Live website:** [Open the Small Acts site](https://ciyon1610.github.io/small-acts-community-project/)

A standalone student project website about a campus volunteer group. Open `index.html` to view it. It includes project cards, a sample impact section, a month timeline, and a volunteer call to action.

Built with HTML, CSS, and JavaScript. The figures and initiative details are sample content. Photos and fonts load from external services.
